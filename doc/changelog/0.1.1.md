# expqueue 0.1.1 (2026-10-15)

The admin pages follow the administration's styling rules.

## Updated

- Updated: Setup > Job queue is drawn with the administration's shared components (cards, tables, key figures,
  badges, tags, buttons, notices, empty states, meters) and its `--a4-*` tokens, so the pages follow admin4's dark mode
  and look like the other admin pages in admin, admin4 and admin4l.
- Updated: Bars, progress meters and spacing no longer use `style=""`: amounts are `.a4-pct-<n>` classes.
- Updated: The history of a job colours its events like the job states.

## Added

- Added: `design/admin/stylesheets/expqueue.css` (`.a4-queue-*`), loaded through `design.ini [StylesheetSettings]
  BackendCSSFileList`, packed and cached by ezjscore.
- Added: The DB-less test `tests/unit/StylingRulesTest.php` with `phpunit.xml.dist`: it fails on a `<style>` block or
  `style=""` in a template, on inline sizes or colours set by a script, and on colour literals or local custom
  properties in a stylesheet.

## Removed

- Removed: `design/admin/templates/expqueue/parts/style.tpl`, the inline `<style>` block of every page.
