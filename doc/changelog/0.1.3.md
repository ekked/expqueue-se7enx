# expqueue 0.1.3 (2026-10-17)

The job queue pages carry no inline script and no event handler attribute, so they run under a Content Security
Policy without `'unsafe-inline'`.

## Updated

- Updated: A control that asks before it is sent (Pause queue, Requeue all, Cancel, Cancel group) declares its
  question in `data-a4-confirm` instead of an inline `onsubmit` handler. admin4 and admin4l ask it with their
  `a4_actions.js`; the other administration designs with `design/admin/javascript/expqueue_confirm.js`, loaded through
  `design.ini [JavaScriptSettings] BackendJavaScriptList`. The question is asked once in every design.
- Updated: `tests/unit/ScriptRulesTest.php` fails on an inline script or an `on...=` attribute in a template.
